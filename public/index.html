METHODOLOGY

How It Works

1. Order / State Bisect: Identifies state polluters and order-dependent consumers via binary permutation bisecting.
2. Seed Sweep: Evaluates unseeded PRNG randomness across varying seeds to isolate threshold flakiness.
3. Schedule-Stress Sweep: Injects thread contention and CPU jitter to surface latent timing races.
4. Regression Separation: Distinguishes genuine deterministic build failures from non-deterministic flakes.
